# 引用

**引用的本质是一个常量指针**（`T* const`），它在底层通过内存地址实现，但在语法层面被设计成类似原始变量的别名，由编译器自动处理解引用。

在大多数编译器的实现中，引用在底层就是通过指针实现的。但是，与普通指针有以下关键区别：

```cpp
int value = 42;

// 引用实现
int& ref = value;
// 底层近似于：int* const ref = &value;

// 指针实现
int* ptr = &value;
```

| 特性         | 引用                    | 指针               |
| ------------ | ----------------------- | ------------------ |
| **底层实现** | `int* const` (常量指针) | `int*` (普通指针)  |
| **内存占用** | 通常占用指针大小的内存  | 占用指针大小的内存 |
| **空值**     | 不能为null，必须初始化  | 可以为nullptr      |
| **重新绑定** | 不能重新绑定到其他变量  | 可以指向不同变量   |
| **语法使用** | 像普通变量一样使用      | 需要解引用操作(*)  |

## 传引用（底层实现）
```cpp
void increment(int& x) {
    x++; // 底层：(*x)++
}

int main() {
    int a = 5;
    increment(a); // 底层：increment(&a)
    // a 现在是 6
}
```

在底层，编译器会将上面的代码处理为类似这样的形式：
```cpp
void increment(int* const x) { // 常量指针参数
    (*x)++; // 解引用并递增
}

int main() {
    int a = 5;
    increment(&a); // 传递地址
}
```

## 为什么要有引用？

既然引用在底层类似指针，为什么C++要引入引用？

1. **语法糖**：让代码更简洁易读
2. **安全性**：不能为null，必须初始化
3. **常量正确性**：支持 `const` 引用
4. **运算符重载**：使运算符重载更自然
5. **避免指针语法**：让代码更像在使用实际对象

## 特殊情况：引用可能不占用存储空间

在某些情况下，编译器可能会优化掉引用，使其不占用实际内存：

```cpp
void optimize() {
    int x = 10;
    int& y = x; // 编译器可能直接使用x，不为y分配存储空间
    std::cout << y; // 可能直接编译为 std::cout << x;
}
```

但这种优化是编译器的选择，不是语言标准的要求。

# 仿函数(Functor)

在C++中，仿函数（也称为函数对象）是重载了函数调用运算符`operator()`的类。使用仿函数时需要加`()`来调用，但在某些上下文中（如传递给算法时）看起来像是没有加`()`，实际上是因为算法内部会调用它。

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <functional>

// 1. 基本仿函数示例
struct Square {
    int operator()(int x) const {
        return x * x;
    }
};

// 2. 带状态的仿函数
class Counter {
    mutable int count; // mutable允许在const成员函数中修改
public:
    Counter() : count(0) {}
    
    int operator()(int x) const {
        count++;
        return x + count;
    }
    
    int getCount() const { return count; }
};

// 3. 使用标准库中的仿函数
void demonstrateStdFunctors() {
    std::vector<int> numbers = {1, 2, 3, 4, 5};
    
    // 使用std::plus仿函数
    std::plus<int> add;
    std::cout << "5 + 3 = " << add(5, 3) << std::endl;
    
    // 使用std::greater仿函数进行排序（降序）
    std::sort(numbers.begin(), numbers.end(), std::greater<int>());
    std::cout << "降序排序: ";
    for (int n : numbers) std::cout << n << " ";
    std::cout << std::endl;
}

int main() {
    // 1. 基本使用 - 需要加()调用
    Square square;
    std::cout << "5的平方: " << square(5) << std::endl; // 这里需要加()
    
    // 2. 带状态的仿函数
    Counter counter;
    std::cout << "counter(10): " << counter(10) << std::endl;
    std::cout << "counter(20): " << counter(20) << std::endl;
    std::cout << "调用次数: " << counter.getCount() << std::endl;
    
    // 3. 在算法中使用仿函数
    std::vector<int> numbers = {1, 2, 3, 4, 5};
    
    // 使用自定义仿函数
    std::transform(numbers.begin(), numbers.end(), numbers.begin(), Square());
    std::cout << "平方后的数字: ";
    for (int n : numbers) std::cout << n << " ";
    std::cout << std::endl;
    
    // 4. 使用标准库仿函数
    demonstrateStdFunctors();
    
    // 5. 使用lambda表达式（C++11的另一种函数对象）
    std::vector<int> nums = {1, 2, 3, 4, 5};
    int factor = 3;
    std::transform(nums.begin(), nums.end(), nums.begin(), 
                  [factor](int x) { return x * factor; }); // lambda也是函数对象
    
    std::cout << "乘以因子3后: ";
    for (int n : nums) std::cout << n << " ";
    std::cout << std::endl;
    
    return 0;
}
```

# std::ref
> [std::ref, std::cref - cppreference.com](https://en.cppreference.com/w/cpp/utility/functional/ref.html) 

`std::ref` 是 C++ 标准库中的一个重要工具，用于创建引用包装器。它在函数式编程、多线程编程和需要传递引用的场景中非常有用。

`std::ref` 位于 `<functional>` 头文件中，用于创建一个引用包装器，使得引用可以像值一样被复制和传递。


1. **在STL算法中传递引用**
2. **在线程中传递引用参数**
3. **在std::bind中传递引用参数**
4. **在需要复制引用语义的容器中**

```cpp
#include <functional>
#include <iostream>

void demonstrateBasicRef() {
    int x = 10;
    
    // 创建引用包装器
    std::reference_wrapper<int> ref_x = std::ref(x);
    
    // 通过引用包装器修改原始值
    ref_x.get() = 20;
    
    std::cout << "x = " << x << std::endl; // 输出: x = 20
    
    // 也可以直接使用运算符
    ref_x += 5;
    std::cout << "x = " << x << std::endl; // 输出: x = 25
}
```

```cpp
#include <functional>

std::reference_wrapper<T> std::ref(T& t);    // 创建引用包装器
std::reference_wrapper<const T> std::cref(const T& t); // 创建常量引用包装器
```

```cpp
void modifyValue(int& value, int newValue) {
```

## 示例3: 在std::bind中使用std::ref

```cpp
#include <iostream>
#include <functional>

class Calculator {
public:
    int multiply(int a, int b) const {
        return a * b;
    }
};

void bindExample() {
    Calculator calc;
    int factor = 5;
    
    // 使用std::ref绑定引用参数
    auto multiplyByFactor = std::bind(&Calculator::multiply, &calc, 
                                     std::placeholders::_1, std::ref(factor));
    
    std::cout << "5 * 3 = " << multiplyByFactor(3) << std::endl; // 输出: 15
    
    // 修改factor会影响绑定的函数
    factor = 10;
    std::cout << "10 * 3 = " << multiplyByFactor(3) << std::endl; // 输出: 30
}
```

## std::ref 的工作原理

`std::ref` 实际上创建了一个 `std::reference_wrapper<T>` 对象，这个对象：

1. **可以复制和赋值**（不像普通引用）
2. **可以隐式转换为它所包装的引用类型**
3. **提供 `get()` 方法来获取底层引用**
4. **重载了运算符，使其可以像底层类型一样使用**

## 注意事项

1. **生命周期管理**：确保被引用的对象比引用包装器存活时间更长
2. **性能考虑**：`std::ref` 避免了不必要的对象复制
3. **线程安全**：多个线程通过 `std::ref` 访问同一对象需要同步

```cpp
#include <iostream>
#include <functional>
#include <thread>
#include <mutex>

void threadSafetyExample() {
    int counter = 0;
    std::mutex mtx;
    
    auto increment = [&counter, &mtx]() {
        for (int i = 0; i < 1000; ++i) {
            std::lock_guard<std::mutex> lock(mtx);
            counter++;
        }
    };
    
    std::thread t1(increment);
    std::thread t2(increment);
    
    t1.join();
    t2.join();
    
    std::cout << "Counter: " << counter << std::endl; // 应该输出 2000
}
```

`std::reference_wrapper` 是一个模板类，它提供了一种将引用包装成可复制、可赋值对象的方法。

```cpp
}
```

## 示例 2: 函数调用运算符重载

```cpp
#include <iostream>
#include <functional>

void functionCallOperator() {
    int value = 10;
    auto ref_val = std::ref(value);
    
    // reference_wrapper 重载了函数调用运算符
    // 这使得它可以用于需要函数对象的场景
    
    // 示例：在算法中使用
    std::vector<int> numbers = {1, 2, 3, 4, 5};
    
    // 创建一个可调用的引用包装器
    auto processor = [](std::reference_wrapper<int> ref) {
        ref.get() *= 2;  // 修改原始值
    };
    
    // 使用 for_each 处理每个元素的引用
    std::for_each(numbers.begin(), numbers.end(), 
                 [](int& n) { n *= 2; });  // 传统方式
    
    // 或者使用引用包装器
    std::vector<std::reference_wrapper<int>> ref_numbers;
    for (int& n : numbers) {
        ref_numbers.push_back(std::ref(n));
    }
    
    for (auto& ref : ref_numbers) {
        ref.get() += 1;  // 通过引用包装器修改
    }
    
    for (int n : numbers) {
        std::cout << n << " ";  // 输出修改后的值
    }
    std::cout << std::endl;
}
```

## 示例 3: 与 STL 算法结合

```cpp
#include <iostream>
#include <functional>
#include <vector>
#include <algorithm>
#include <numeric>

void stlAlgorithmIntegration() {
    std::vector<int> data = {1, 2, 3, 4, 5};
    
    // 场景 1: 使用引用包装器避免复制
    int sum = 0;
    std::for_each(data.begin(), data.end(),
                 [&sum](int n) { sum += n; });
    
    // 使用引用包装器更明确地表达意图
    auto sum_ref = std::ref(sum);
    std::for_each(data.begin(), data.end(),
                 [sum_ref](int n) mutable { sum_ref.get() += n; });
    
    std::cout << "Sum: " << sum << std::endl;
    
    // 场景 2: 转换并存储引用
    std::vector<std::reference_wrapper<int>> even_numbers;
    std::copy_if(data.begin(), data.end(),
                std::back_inserter(even_numbers),
                [](int n) { return n % 2 == 0; });
    
    // 修改偶数元素
    for (auto& ref : even_numbers) {
        ref.get() *= 10;
    }
    
    std::cout << "Modified data: ";
    for (int n : data) std::cout << n << " ";
    std::cout << std::endl;
}
```

## 和普通引用区别
```cpp
#include <iostream>
#include <functional>
#include <vector>

void demonstrateDifference() {
    int a = 1, b = 2, c = 3;
    
    std::cout << "=== 场景1: 普通值容器 ===" << std::endl;
    // 普通值容器 - 存储的是值的副本
    std::vector<int> values = {a, b, c};
    
    // 修改容器中的元素
    for (auto& val : values) {
        val *= 2;
    }
    
    std::cout << "容器中的值: ";
    for (auto val : values) std::cout << val << " "; // 2, 4, 6
    std::cout << std::endl;
    
    std::cout << "原始变量: a=" << a << ", b=" << b << ", c=" << c << std::endl; // 1, 2, 3
    // 注意：原始变量没有被修改！
    
    std::cout << "\n=== 场景2: 引用包装器容器 ===" << std::endl;
    // 引用包装器容器 - 存储的是对原始变量的引用
    std::vector<std::reference_wrapper<int>> refs = {std::ref(a), std::ref(b), std::ref(c)};
    
    // 修改容器中的元素
    for (auto& ref : refs) {
        ref.get() *= 2;
    }
    
    std::cout << "容器引用的值: ";
    for (auto ref : refs) std::cout << ref.get() << " "; // 2, 4, 6
    std::cout << std::endl;
    
    std::cout << "原始变量: a=" << a << ", b=" << b << ", c=" << c << std::endl; // 2, 4, 6
    // 原始变量被修改了！
}

int main() {
    demonstrateDifference();
    return 0;
}
```

## 场景1：管理大型对象的集合

```cpp
#include <iostream>
#include <functional>
#include <vector>
#include <string>

class LargeObject {
    std::string data;
public:
    LargeObject(const std::string& d) : data(d) {}
    void process() {
        std::cout << "Processing: " << data << std::endl;
    }
    void update(const std::string& newData) {
        data = newData;
    }
    std::string getData() const { return data; }
};

void largeObjectExample() {
    // 创建一些大型对象
    LargeObject obj1("Object 1 - very large data...");
    LargeObject obj2("Object 2 - very large data...");
    LargeObject obj3("Object 3 - very large data...");
    
    // 使用引用包装器避免复制大型对象
    std::vector<std::reference_wrapper<LargeObject>> objects = {std::ref(obj1), std::ref(obj2), std::ref(obj3)};
    
    // 处理所有对象（不需要复制）
    for (auto& obj_ref : objects) {
        obj_ref.get().process();
    }
    
    // 修改所有对象
    for (auto& obj_ref : objects) {
        obj_ref.get().update("Updated data");
    }
    
    // 验证修改
    std::cout << "After update: " << obj1.getData() << std::endl;
}
```

## 场景3：在算法中保持对原始数据的引用

```cpp
#include <iostream>
#include <functional>
#include <vector>
#include <algorithm>

void algorithmReferenceExample() {
    std::vector<int> data = {5, 2, 8, 1, 9};
    
    // 创建对原始数据元素的引用容器
    std::vector<std::reference_wrapper<int>> data_refs;
    for (int& item : data) {
        data_refs.push_back(std::ref(item));
    }
    
    // 对引用进行排序（会影响原始数据）
    std::sort(data_refs.begin(), data_refs.end(), 
              [](auto a, auto b) { return a.get() < b.get(); });
    
    std::cout << "排序后的引用: ";
    for (auto ref : data_refs) std::cout << ref.get() << " ";
    std::cout << std::endl;
    
    std::cout << "原始数据: ";
    for (auto item : data) std::cout << item << " ";
    std::cout << std::endl;
    // 注意：原始数据也被重新排列了！
}
```

## 总结

引用包装器容器的主要意义：

1. **避免不必要的对象复制** - 特别是对于大型对象
2. **保持对原始数据的引用** - 修改容器元素会影响原始数据
3. **支持多态** - 可以存储基类引用，实现运行时多态
4. **选择性处理** - 可以创建只包含特定元素的"视图"
5. **内存效率** - 不复制数据，只存储引用

相比之下，普通值容器：
- 存储的是数据的副本
- 修改容器元素不会影响原始数据
- 可能涉及昂贵的复制操作

因此，`std::reference_wrapper` 容器在需要"视图"或"代理"模式时非常有用，让你能够高效地操作原始数据而不进行复制。
