# `std::result_of`

`std::result_of` 是 C++11 引入的一个**类型特征（type trait）**，用于在编译时推导可调用对象的返回类型。

```cpp
#include <type_traits>

// 基本形式
std::result_of<F(ArgTypes...)>::type

// C++14 起的便利别名
std::result_of_t<F(ArgTypes...)>
```

**重要**：`std::result_of` 接受的是**类型**，而不是值！

## 工作原理

`std::result_of` 在**编译时**计算：如果用 `ArgTypes...` 类型的参数调用类型为 `F` 的可调用对象，会得到什么返回类型。

```cpp
#include <type_traits>

int func(double, char);  // 一个函数声明

// 推导 func 使用 double 和 char 参数调用时的返回类型
using result_type = std::result_of<decltype(func)(double, char)>::type;
// result_type 就是 int
```

## 基本函数类型推导

```cpp
#include <iostream>
#include <type_traits>

int add(int a, int b) { return a + b; }

int main() {
    // 推导函数类型
    using func_type1 = std::result_of<decltype(add)(int, int)>::type;
    // 等价于
    using func_type2 = std::result_of<int(int, int)>::type;
    
    static_assert(std::is_same<func_type1, int>::value, "类型应该是 int");
    static_assert(std::is_same<func_type2, int>::value, "类型应该是 int");
    
    std::cout << "add 函数的返回类型是: int" << std::endl;
    return 0;
}
```

## 函数指针推导

```cpp
#include <type_traits>

double multiply(double x, double y) { return x * y; }

// 函数指针类型
using FuncPtr = double(*)(double, double);

// 推导函数指针的返回类型
using result_type = std::result_of<FuncPtr(double, double)>::type;
// result_type 是 double
```

## 函数对象（Functor）推导

```cpp
#include <type_traits>

struct Adder {
    int operator()(int a, int b) const {
        return a + b;
    }
};

// 推导函数对象的返回类型
using result_type = std::result_of<Adder(int, int)>::type;
// result_type 是 int
```

## Lambda 表达式推导

```cpp
#include <type_traits>

auto lambda = [](int x, int y) -> double { return x + y; };

// 推导 lambda 的返回类型
using result_type = std::result_of<decltype(lambda)(int, int)>::type;
// result_type 是 double
```

## 在线程池中的具体应用

```cpp
template<class F, class... Args>
auto enqueue(F&& f, Args&&... args) 
    -> std::future<typename std::result_of<F(Args...)>::type>
{
    // 使用 using 别名简化代码
    using return_type = typename std::result_of<F(Args...)>::type;
    
    // 现在可以创建 packaged_task
    auto task = std::make_shared<std::packaged_task<return_type()>>(
        std::bind(std::forward<F>(f), std::forward<Args>(args)...)
    );
    
    // 返回对应类型的 future
    std::future<return_type> res = task->get_future();
    return res;
}
```

假设这样调用：
```cpp
ThreadPool pool(4);
auto future = pool.enqueue([](int a, int b) { return a + b; }, 5, 3);
```

推导过程：
1. **`F`** = `decltype(lambda)`（lambda 的类型）
2. **`Args...`** = `int, int`（参数类型）
3. **`std::result_of<F(Args...)>::type`** = `std::result_of<lambda_type(int, int)>::type`
4. 由于 lambda 返回 `int`，所以最终类型是 `int`
5. 返回类型 = `std::future<int>`

## 6. 与 `decltype` 的区别

`std::result_of` 和 `decltype` 都可以用于类型推导，但用法不同：

```cpp
// 使用 std::result_of（编译时推导）
using type1 = std::result_of<F(Args...)>::type;

// 使用 decltype（需要实际表达式）
// 注意：这里 f 必须是一个可用的对象，不能只是类型
using type2 = decltype(f(args...));
```

**关键区别**：
- `std::result_of` 基于**类型**进行推导
- `decltype` 基于**表达式**进行推导

## C++17 中的替代品：`std::invoke_result`

C++17 引入了 `std::invoke_result` 作为 `std::result_of` 的替代品：

```cpp
// C++11/C++14 方式
using old_way = typename std::result_of<F(Args...)>::type;

// C++17 新方式
using new_way = std::invoke_result_t<F, Args...>;
```

- `std::result_of` 的语法 `F(Args...)` 容易让人误解为函数调用
- `std::invoke_result` 语法更清晰，直接列出类型
- `std::invoke_result` 更准确地处理了 `std::invoke` 的语义

## 总结

`std::result_of` 是一个强大的编译时类型推导工具：

- **用途**：推导可调用对象的返回类型
- **时机**：在编译时进行计算
- **输入**：类型（不是值）
- **输出**：通过 `::type` 成员访问推导结果

虽然 C++17 推荐使用 `std::invoke_result`，但理解 `std::result_of` 对于维护现有代码和理解类型推导机制仍然非常重要。
